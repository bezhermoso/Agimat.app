Agimat is a free macOS app. Open it with a keyboard shortcut, search by name or codepoint, and press Return to insert the character at your cursor.

## Features

- Search about 20,000 emoji, symbols and characters by name, keyword, your own aliases, or codepoint.
- Aliases: give a character your own short name, so `lgtm` finds 👍.
- <kbd>⌘D</kbd> adds a favorite. With an empty search, the palette shows your recent characters.
- <kbd>⌘I</kbd> shows a character's name, codepoint, Unicode block and category.
- Keyboard-centric: move the selection with the arrow keys or vim-style <kbd>⌃H</kbd> <kbd>⌃J</kbd> <kbd>⌃K</kbd> <kbd>⌃L</kbd>. <kbd>⌘1</kbd>–<kbd>⌘4</kbd> switch to Favorites, Emoji, Symbols or Punctuation. <kbd>Esc</kbd> goes back to All, then closes.
- Set a default skin tone, or choose one each time.

## Install

Download Agimat from [bez.dev/apps/agimat](https://bez.dev/apps/agimat/). Requires macOS 26 or later.

## Privacy

Agimat has no account and no analytics. Search works offline, and your history stays on your Mac. See the [privacy policy](https://bez.dev/apps/agimat/privacy/).
